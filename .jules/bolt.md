## 2026-05-23 - [Supabase payload sizes and array iterations]
**Learning:** Selecting all columns using `select('*')` on joined Supabase relationships can result in very heavy payloads across the wire and cause slow memory allocations when rendering data, specifically counts. Also chained Javascript array methods (like `filter()`, `reduce()`, `forEach()`) are costly when aggregating data across larger nested arrays due to repeated allocations.
**Action:** Replace `select('*')` queries with explicitly required columns (e.g. `select('id, name')`). Use `{ count: 'exact', head: true }` when only row count is needed to avoid heavy payloads. Replace chained array array methods with a single standard `for` loop to minimize intermediate memory allocations and loop through data faster in memory.

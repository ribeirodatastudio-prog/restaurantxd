## 2024-05-15 - Optimizing Supabase count and payloads
**Learning:** When using `{ count: 'exact', head: true }` in Supabase, remember to use nullish coalescing to extract the count since the data payload is omitted. Also, joined table relationships (like `restaurant:restaurants(...)`) can sometimes resolve as an array or single object depending on constraints; always handle both formats defensively (e.g., `Array.isArray(rel) ? rel[0] : rel`). Replacing chained array methods (`.filter().reduce()`) with single-pass `for` loops significantly improves Javascript execution times for array aggregations.
**Action:** For all future data fetching, explicitly select required fields rather than `*`. Utilize database count operations instead of fetching all records for lengths. Combine array operations into single loops to optimize memory and speed.
